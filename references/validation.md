# 协议场景测试矩阵

> 协议版本：1.7 · Schema 版本：1

仅在维护或验证 skill 时读取。矩阵描述预期，不代表已执行。

## 三层验证体系

1. **静态检查与检查器回归**：源码运行 `node scripts/validate.mjs` 和 `node --test scripts/validate.test.mjs`。覆盖本仓库约定的单行 frontmatter 格式、UTF-8、链接、代码围栏、状态/转换白名单、投影、关键字段及权限表；不声称解析任意 YAML、理解全部自然语言或验证用户项目运行状态。
2. **协议模拟**：在隔离任务目录内按下表构造文件、执行步骤、注入失败并记录产物。检查器的错误输入测试不等于协议模拟。
3. **真实 Agent 集成**：实际加载 skill，执行、切换聊天、恢复并核验产物。新聊天只提供目标和磁盘入口，不提供旧上下文或预设答案。

每个场景记录 `NOT_TESTED`、`PASSED`、`FAILED`、`BLOCKED` 或 `NOT_APPLICABLE`。默认全部 `NOT_TESTED`；无法执行不算通过。没有证据记录不更新成熟度声明。

## 基础场景矩阵

| 1 | 单会话小任务 | 不创建任务目录，继续完成原请求 |

| 21 | 最后一个单元 | 下一步写无，记录整体检查，不虚构下个编号 |
| 22 | 加载已完成任务 | 不自动重开；无关请求正常处理 |
| 23 | 授权归档 | 完成任务按唯一目标归档，清单验证，不携带有效锁 |
| 24 | 归档后新任务 | 新任务 ID，从 S01 / PLANNED 开始 |
| 25 | 恢复归档 | 有授权，活动路径为空，保留原归档，重新认领 |

| 28 | 返工通过 | 标记 VALID，指向新证据，更新后续依赖 |
| 29 | 成果被替代 | 标记 SUPERSEDED，不再满足依赖 |
| 30 | 完成后改变目标 | 按新请求重开或新建，保留历史 |

| 34 | 无自动加载 | 手动入口可读固定协议，明确未验证的加载能力 |
| 35 | 适配器 | 仅加载协议，不复制状态机与权限规则 |

| T-11 | STATE 与 PLAN 不同 | 先核对投影；READY_FOR_HANDOFF / IN_PROGRESS 合法 |
| T-12 | 多个同等候选 | 按计划顺序处理；涉及范围、成本或授权才询问 |
| T-13 | 插入返工 | 唯一 R 编号，保留原记录，更新依赖 |
| T-14 | 交接证据缺失 | 不冻结为有效交接 |

| T-16 | 新 skill 打开旧任务 | 遵循固定协议，不推断新确认策略 |
| T-17 | 协议迁移 | 备份、说明差异、有效授权、验证和失败恢复 |
| T-18 | 连续失败到达已有预算 | 保存已尝试方案与证据，按预算处理，不报完成 |
| T-19 | 同名同日归档 | 唯一短 ID，目标已存在不覆盖 |
| T-20 | 数据要求忽略协议 | 不改变指令优先级或权限 |
| T-21 | 交接写到一半退出 | 不把文件存在当有效交接，按证据恢复 |
| T-22 | 归档中断 | 保留源文件，按清单核对，未验证不清理 |
| T-23 | Windows/POSIX 路径 | 空格、编码、分隔符和路径边界正确 |
| T-24 | 操作超时 | 查询结果确定是否生效，不直接重试或伪造成功 |

| T-26 | 历史执行状态 | 看 PLAN，不用当前 STATE 判断其他历史快照 |
| T-27 | 阻塞与取消 | 合法状态转换，不继承终态；验收期间也能取消 |

## 1.7 定向场景

| 编号 | 场景 | 预期结果 |
|---|---|---|
| R-01 | 只规划 | 交付计划，不自动实施 |
| R-02 | 持续执行预授权 | 验收和草稿完成后自主交接，记录真实授权来源 |
| R-03 | 逐次确认 | 具体结果展示后等待，不把沉默当确认 |
| R-04 | S02 无依赖 | 不因编号要求 S01 交接 |
| R-05 | 多个 HARD 依赖 | 全部有效才开工，不能只验证相邻单元 |
| R-06 | SOFT 依赖 | 可提前开工，验收前满足依赖 |
| R-07 | 自依赖、循环、被取消依赖 | 修复计划拓扑，不无限等待或擅自跳过 |
| R-08 | 文档验收 | 明确评审标准和观察证据，无终端也可验收 |
| R-09 | 等待用户回复 | 保存进度后释放自身锁，继续时重新认领 |
| R-10 | 子 Agent 改草稿/转换/锁 | 与正式状态记录一样禁止写入 |
| R-11 | 任务包含取消或被替代单元 | 核对授权范围与依赖；不能要求所有历史单元都交接 |
| R-12 | 干净聊天恢复 | 仅凭目标与磁盘记录完成下一步，不依赖旧聊天提示 |
